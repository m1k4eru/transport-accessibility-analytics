## Главные фичи

* **Автогенерация текста (NLG):** Аналитическое заключение слева пишется и меняется автоматически при переключении слайдеров и фильтров.
* **100% собственный сбор данных:** Данные собраны с нуля на основе замеров, открытых источников и матриц корреспонденций.
* **Авторский PTWAI:** Базовый индекс доработан — добавлен штраф за время ожидания транспорта и оценка ТПУ.
* **Имитационное моделирование:** Симуляция пассажиропотоков для расчета реальных задержек и нагрузок.
* **Детализация (Drill-through):** Главная карта + детальные карточки округов при наведении.

## 📐 DAX-логика и Математическая модель

В репозитории представлены ключевые примеры расчетных мер, обеспечивающих динамический пересчет индексов, What-If сценарии и автогенерацию текстовых выводов.

<details>
<summary><b>1. Модифицированный динамический индекс (PTWAI)</b></summary>
<p><i>Рассчитывает скорректированное время в пути с учетом коэффициента ожидания, штрафа и времени движения, переводя итоговый результат в 12-балльную шкалу доступности.</i></p>

<pre><code>Динамический индекс = 
VAR SelectedWaiting = AVERAGE('Ожидание'[Ожидание])
RETURN
AVERAGEX(
    KEEPFILTERS(
        SUMMARIZE('Лист1', 'Лист1'[Город], 'Лист1'[Категория])
    ),
    VAR AdjustedTime = 
        (CALCULATE(AVERAGE('Лист1'[Ожидание])) * SelectedWaiting + CALCULATE(AVERAGE('Лист1'[Штраф])) + CALCULATE(AVERAGE('Лист1'[Чистое время в пути (мин)]))) -- т.к. через SUM суммировались все числа, пришлось сделать упрощение и остановиться на среднем
    RETURN
    SWITCH(TRUE(),
        AdjustedTime < 10, 12,
        AdjustedTime < 20, 11,
        AdjustedTime < 30, 10,
        AdjustedTime < 40, 9,
        AdjustedTime < 50, 8,
        AdjustedTime < 60, 7,
        AdjustedTime < 70, 6,
        AdjustedTime < 80, 5,
        AdjustedTime < 90, 4,
        AdjustedTime < 100, 3,
        AdjustedTime < 110, 2,
        AdjustedTime < 120, 1,
        0
    )
)</code></pre>
</details>

<details>
<summary><b>2. Динамический генератор заголовка (NLG)</b></summary>
<p><i>Автоматически формирует контекстный заголовок дашборда на основе выбранного режима анализа и среза по городскому округу.</i></p>

<pre><code>Заголовок сводки = 
VAR SelectedCity = SELECTEDVALUE('Данные'[Городской округ], "Московская область")
VAR WaitTime = SELECTEDVALUE('Ожидание'[Ожидание])
VAR CurrentMode = MAX('Параметр'[Параметр])

RETURN
SWITCH( TRUE(),
    CurrentMode = "ИНДЕКС", "Карта доступности: " & SelectedCity,
    CurrentMode = "НАСЕЛЕНИЕ", "Плотность населения 2025: " & SelectedCity,
    "Выберите режим для анализа"
)</code></pre>
</details>

<details>
<summary><b>3. Расчет населения в зоне риска (Критическая зона)</b></summary>
<p><i>Агрегирует численность населения по округам, где динамический индекс доступности опустился ниже порогового значения (Threshold < 4).</i></p>

<pre><code>Население в КЗ_Фикс = 
VAR Threshold = 4
RETURN
CALCULATE(
    SUM('Данные'[Население 2025]),
    KEEPFILTERS(
        FILTER(
            ALL('Данные'[Городской округ]), -- чистый список городов
            CALCULATE([Динамический индекс]) < Threshold && CALCULATE([Динамический индекс]) > 0
        )
    )
)</code></pre>
</details>
